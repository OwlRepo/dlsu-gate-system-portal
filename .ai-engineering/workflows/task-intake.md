# Task Intake

Every task needs: objective, acceptance criteria, priority, risks, unknowns, dependencies. Unknown requirements become blockers (`workflows/blockers.md`). Linear issues get a planning-triage pass first (`../docs/agents/issue-tracker.md`).

Classification — the routing table, the Tiny/Express/Standard/Deep size vocabulary, the ambiguity rule, the mandatory `Task Classification:` block, the post-classification lookup order and the drift markers — lives in one place: `../docs/ai/task-router.md` (moved there 2026-09-23 with the workflow port; this file keeps only the intake requirements above).
