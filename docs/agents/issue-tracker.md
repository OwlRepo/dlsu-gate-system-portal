# Issue tracker: Linear

Issues live in Linear, not this repo. Romeo Angeles Jr. is a solo fullstack AI engineer — issues get created when someone raises a concern, or after a meeting surfaces new requests.

## Conventions

- No CLI/API integration configured yet — issues are tracked directly in Linear's UI.
- Agents treat open Linear issues as **Romeo's todos**.
- Before acting on any issue, **always run a planning-triage pass first** — don't jump straight to implementation. Confirm scope and priority so work stays efficient, not reactive.

## When a skill says "publish to the issue tracker"

Ask Romeo — there's no automated write path to Linear configured. Describe what would be filed and let him create it, or add Linear MCP/API wiring later if this becomes frequent.

## When a skill says "fetch the relevant ticket"

Ask Romeo to paste the Linear issue content — no automated read path is configured.
